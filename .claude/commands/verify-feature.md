Use Chrome to verify that a feature works end-to-end in a real browser.

Process:
1. Open Chrome and navigate to the application
2. Visit the feature page or flow
3. Test the complete user flow
4. Verify all interactions work correctly
5. Check for console errors
6. Confirm expected behavior
7. Report on success or issues

For UI features:
- Test all interactions
- Verify visual elements appear
- Check responsive behavior
- Confirm animations/transitions

For forms:
- Fill all required fields
- Test validation
- Submit and verify response
- Check success/error messages

For navigation:
- Test all links
- Verify routes work
- Check redirects
- Confirm page loads

For API integration:
- Verify data loads
- Test create/update/delete
- Check error handling
- Confirm responses

Provide detailed feedback:
- What worked correctly
- What didn't work
- Any errors or warnings
- Suggestions for improvements
- Screenshots if helpful (describe what you see)

Remember: This is for verification during development. Still write dedicated browser tests for CI/CD.
