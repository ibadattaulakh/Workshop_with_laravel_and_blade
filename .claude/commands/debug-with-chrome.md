---

Use Chrome to debug client-side issues in the application.

Process:
1. Open Chrome and navigate to the problematic page
2. Check the browser console for errors
3. Read console logs and identify issues
4. Check network requests for failed resources
5. Inspect page elements if needed
6. Identify the root cause
7. Suggest specific fixes

Common issues to check:
- JavaScript errors in console
- Failed network requests
- Missing resources (CSS, JS files)
- Route errors
- Form validation issues
- API endpoint errors

For white screens:
- Check console for errors
- Verify routes are correct
- Check if server is running
- Verify assets are loading

For form issues:
- Check validation errors
- Verify form submission
- Check API responses
- Verify success/error handling

Provide:
- Specific error messages
- Root cause analysis
- Suggested fixes
- Steps to reproduce (if needed)
