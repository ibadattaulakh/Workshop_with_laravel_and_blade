Use Chrome to test the application in a real browser.

Process:
1. Open Chrome and navigate to the application
2. Visit the specified page or flow
3. Interact with the page (click buttons, fill forms, etc.)
4. Verify the behavior works correctly
5. Check for any console errors
6. Report back on what works and what doesn't

If testing a form:
- Ask about required fields
- Fill form with appropriate test values
- Submit and verify success/error handling

If debugging an issue:
- Read console logs
- Identify JavaScript errors
- Check network requests
- Suggest fixes

If verifying a feature:
- Test the complete flow
- Verify all interactions work
- Confirm expected behavior
- Report any issues found

Provide specific feedback on:
- What worked
- What didn't work
- Any errors found
- Suggestions for fixes
